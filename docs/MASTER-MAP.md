# 말결 — 지도 (MASTER-MAP)

> 말결의 방향·범위·상태를 판정하는 유일한 정본이다.

## 1 Project Charter

- 목표: 스마트폰 사용과 외출이 어려운 재가 어르신이 일반 전화로 개인별지원계획 안의 식사·식품·생필품 지원을 요청하고, 수행기관의 제공과 수령 결과까지 확인할 수 있게 한다. [D-20260917-01]
- 최종 산출물: 전화 이용자 흐름, 수행기관 업무함, 예외 담당자 이관, 감사 가능한 서비스 이행 원장, 서울시 정책·데이터·실증환경·지원 제안 1장. [D-20260917-01]
- 승리·성공 논리: AI 대화 성능이 아니라 정상 요청의 공무원 무개입 종결률, 공무원 처리시간 감소, 실제 수령률, 승인·제공·수령 기록 일치로 가치를 증명한다. [D-20260917-01]
- 가드레일: AI는 신규 자격·급여·개인별지원계획을 결정하지 않는다. 승인 범위 밖 요청과 위험 신호는 사람에게 이관한다. 개인정보를 최소화하고 실제 제공 결과를 만들지 않는다. [D-20260917-01]
- 명시적 비목표: 이용자 결제, 범용 쇼핑, 농식품바우처 잔액 소비, 암호자산·블록체인, 서울시 기존 시스템 전면 교체, 24시간 공공기관 처리를 주장하지 않는다. [D-20260917-01]

## 3 Confirmed Scope

- 법적 뿌리는 돌봄통합지원법과 서울시 지역사회 돌봄 통합지원 체계다. [D-20260917-01]
- 말결은 개인별지원계획을 새로 판단하지 않고 승인된 서비스를 전화로 실행한다. [D-20260917-01]
- 긴급 식사는 돌봄SOS, 식품·생필품은 찾아가는 푸드마켓 또는 가정 배달이 가능한 협약 수행기관에 연결한다. [D-20260917-01]
- 기존 주문 성공 업체와 배달 플랫폼은 정책 기반이 아니라 자치구가 승인할 때만 쓰는 교체 가능한 공급자 어댑터다. [D-20260917-01]
- 첫 공공 실증에는 이용자 결제 기능을 포함하지 않는다. [D-20260917-01]
- 정상 요청은 수행기관으로 직접 전달하고 예외만 공무원에게 이관해 행정업무를 줄인다. [D-20260917-01]
- 프로젝트 저장소는 비공개·권리유보 원칙을 유지하며 외부 팀원에게 전체 저장소 권한을 전제로 하지 않는다. [D-20260917-01]
