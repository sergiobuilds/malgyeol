PRODUCT ARCHITECTURE

AI는 말을 정리하고,
공공의 계획이 결정합니다.

말결의 핵심은 모델이 아니라 통제 가능한 서비스 이행 흐름입니다. 개인별지원계획, 수행기관, 전화·AI 제공자는 제한된 인터페이스 뒤에서 분리됩니다.

ONE CASE, ONE TRACE

01 접수전화 요청
02 해석필요 서비스 구조화
03 계획허용 서비스·횟수 확인
04 제공수행기관 수락·이행
05 결과수령·예외·감사 기록

SEPARATION OF AUTHORITY

각 구성요소가 할 수 있는 일을 제한합니다.

AI 해석기

자연어를 구조화하고 되묻기 후보를 만듭니다. 신규 자격·급여·계획은 결정하지 않습니다.

계획 규칙 엔진

버전이 고정된 규칙으로 허용 서비스·횟수·수행기관을 확인하고 같은 입력에는 같은 결과를 냅니다.

좁은 실행 권한

승인된 이용자, 서비스, 수량, 수행기관, 유효기간 안에서만 요청을 한 번 전달합니다.

추가만 가능한 사건 원장

상태를 덮어쓰지 않고 요청·제공·수령 사건을 이어 붙여 감사와 사람의 인계를 가능하게 합니다.

SAFETY BOUNDARY

위험 신호와 계획 밖 요청은 사람에게 갑니다.

개인 식별정보, 자격 변경, 승인 범위 초과와 건강·학대 위험 신호는 자동 처리하지 않습니다. 해석 서비스가 응답하지 않아도 수행기관과 담당자 인계 경로는 유지됩니다.

CURRENT EVIDENCE

확인된 것과 아직 주장하지 않는 것

현재 확인 가능합성 개인별지원계획, 서비스 범위 확인, 요청 생성, 수행기관 수락, 제공·수령·예외 이력
과거 기술 증거국내 전화 입력 경로와 공급자 주문 연동. 현행 공공 실증에서는 결제 경로를 사용하지 않음
아직 연결하지 않음서울시·자치구 시스템, 실제 개인별지원계획, 푸드마켓 재고, 실제 수혜자 개인정보
파일럿 검증 항목공무원 처리시간, 수행기관 수락 시간, 무개입 종결률, 실제 수령률, 기록 일치율
말결 기술 개요 · 시연 환경의 경계를 사실대로 표시합니다.
